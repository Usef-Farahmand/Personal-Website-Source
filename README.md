# Usef Farahmand — Personal Website

The personal website and digital portfolio of **Usef Farahmand** — game developer & technical artist, founder of **Jolly Panda Studio**. Built as a modern, bilingual (English/Persian) interactive experience rather than a traditional static resume site: it showcases shipped projects, work experience, skills, achievements, articles, and recommendations, with a full Persian (RTL) translation alongside English.

> A content-editing guide (in Persian) is available at [`doc/CONTENT_GUIDE_fa.md`](./doc/CONTENT_GUIDE_fa.md) for anyone updating the site's text, projects, articles, or other content without touching application code.

## Tech Stack

- **[Next.js](https://nextjs.org) 16** (App Router) — React 19
- **TypeScript** — strict typing throughout
- **[next-intl](https://next-intl.dev)** — internationalization (`en` / `fa`, with full RTL support for Persian)
- **Tailwind CSS 4** — utility-first styling
- **[Radix UI](https://www.radix-ui.com)** — accessible primitives (e.g. Dialog)
- **[anime.js](https://animejs.com)** — purposeful, meaningful motion
- **[EmailJS](https://www.emailjs.com)** — client-side contact form email delivery
- **[lucide-react](https://lucide.dev)** — icons
- **Fontsource** — Geist, Geist Mono, and Vazirmatn (for Persian) self-hosted fonts

## Content Model

Every content type (Project, Article, Experience, Skill, Achievement, Recommendation, ...) separates **shared fields** (identical regardless of language) from a **`translations` map** with one localized field set per locale (`en`, `fa`). Components never read raw content directly — they consume a *resolved* shape (shared fields + one locale's translation) produced by the content-access layer in `src/lib/content.ts`.

> **Note:** Projects and Articles are the two content types wired to a CMS export step. Their data lives in `src/content/generated/{projects,articles}.json`, generated by `npm run content:export` from a companion `cms/` project (not included in this repository export). The matching `projects.data.ts` / `articles.data.ts` files remain as pre-CMS authoring history but are no longer imported by the site — edit the generated JSON directly, or restore the `cms/` tooling, to change this content. Every other content type is edited directly in its `*.data.ts` (or `.json`) file under `src/content/`.

For a full walkthrough of exactly which file to edit for each part of the site — with field-by-field explanations and copy-paste examples — see **[`doc/CONTENT_GUIDE_fa.md`](./doc/CONTENT_GUIDE_fa.md)** (written in Persian for the site owner).

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site. Both locales are available at `/en` and `/fa`.

### Other scripts

```bash
npm run build         # Production build
npm run start          # Start the production server
npm run lint            # Run ESLint
npm run format          # Format the codebase with Prettier
npm run format:check    # Check formatting without writing changes
```

## Environment Variables

The contact form sends email via EmailJS and requires the following variables in a `.env.local` file:

```
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
```

Optionally, override the canonical site URL used for metadata/OG images:

```
NEXT_PUBLIC_SITE_URL=https://www.useffarahmand.com
```

Without EmailJS configured, the contact form gracefully falls back to a "not configured" message instead of failing silently.

## Internationalization

- Locales: **English (`en`)** and **Persian (`fa`)**, routed via `[locale]` segments (`next-intl`).
- Persian renders right-to-left automatically.
- Static UI strings (navigation, buttons, form labels) live in `src/messages/en.json` and `src/messages/fa.json`.
- All authored content (projects, articles, bio, etc.) carries its own per-locale translations inline, as described in the Content Model section above.
