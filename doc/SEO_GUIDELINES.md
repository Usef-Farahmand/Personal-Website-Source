# Purpose

This document defines the SEO strategy for the website.

The objective is to maximize long-term organic visibility while maintaining an excellent user experience.

SEO should support the content, never dictate it.

---

# SEO Philosophy

Write for humans first.

Optimize for search engines second.

Every page should provide genuine value.

Avoid creating pages purely to rank.

---

# Primary SEO Goals

- Build long-term organic traffic.
- Establish technical authority.
- Increase discoverability.
- Strengthen personal branding.
- Support product discovery.
- Improve article visibility.

---

# URL Structure

Use clean URLs.

Good

/projects/personal-ai

/articles/designing-a-motion-system

Avoid

/projects?id=12

/article/000123

URLs should be

- lowercase
- hyphen-separated
- short
- descriptive

---

# Metadata

Every page requires

- Title
- Description
- Canonical URL
- Open Graph Image
- Twitter Card
- Robots Directive

Titles should be unique.

Descriptions should summarize the page naturally.

---

# Title Guidelines

Length

50–60 characters

Include

Primary Topic

Brand Name

Example

Building an AI Assistant with Next.js | Usef Farahmand

---

# Meta Description

Length

140–160 characters

Should explain

- what the page is
- why it matters

Avoid keyword repetition.

---

# Headings

Each page must contain

One H1

Logical H2 hierarchy

Logical H3 hierarchy

Never skip heading levels unnecessarily.

---

# Semantic HTML

Prefer

header

main

nav

section

article

aside

footer

Avoid unnecessary div nesting.

---

# Internal Linking

Every article should link to

- Related Projects
- Related Articles
- Technologies
- About

Every project should link to

- Articles
- GitHub
- Demo
- Related Skills

---

# External Linking

Link only to trusted sources.

Open external links securely.

Provide context for every external link.

---

# Images

Every image requires

- alt text
- descriptive filename
- responsive sizing
- lazy loading

Prefer modern formats

- AVIF
- WebP

Avoid oversized images.

---

# Open Graph

Every page should define

- title
- description
- image
- url
- type

Each project should have its own OG image.

Each article should have its own OG image.

---

# Twitter Cards

Support

summary_large_image

for every shareable page.

---

# Structured Data

Implement JSON-LD.

Required schemas

- Person
- Organization
- Website
- WebPage
- BreadcrumbList
- Article
- BlogPosting
- SoftwareSourceCode
- CreativeWork
- Project (when appropriate)

Future

- FAQ
- Speakable
- VideoObject

---

# XML Sitemap

Generate automatically.

Include

- Pages
- Articles
- Projects

Exclude

- Drafts
- Admin
- Private Routes

---

# robots.txt

Allow indexing of public pages.

Disallow

/admin

/api/private

Draft content

---

# Canonical URLs

Every public page must define a canonical URL.

Avoid duplicate content.

---

# Breadcrumbs

Use breadcrumbs where appropriate.

Especially

- Projects
- Articles

Implement BreadcrumbList schema.

---

# Performance

SEO depends on performance.

Target

Performance >95

CLS <0.1

LCP <2s

INP Excellent

---

# Core Web Vitals

Optimize

- Images
- Fonts
- JavaScript
- CSS
- Animations

Avoid render-blocking resources.

---

# Font Optimization

Use

next/font

Avoid loading unnecessary font weights.

Use font-display: swap.

---

# JavaScript

Ship as little JavaScript as possible.

Prefer

Server Components

Lazy Loading

Dynamic Imports

---

# Accessibility

Accessibility directly supports SEO.

Support

- keyboard navigation
- semantic HTML
- descriptive labels
- sufficient contrast
- readable typography

---

# Mobile SEO

Design mobile-first.

Touch targets should be accessible.

Avoid horizontal scrolling.
