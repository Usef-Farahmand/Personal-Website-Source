# Purpose

The Design System defines the visual language, interaction rules, reusable components, spacing system, typography, color palette, and motion principles used across the entire website.

Every design decision must follow this document to ensure consistency and scalability.

---

# Design Philosophy

The website should feel:

- Modern
- Premium
- Calm
- Interactive
- Intentional
- Minimal
- Technical
- Creative

Every visual element should communicate quality.

Avoid unnecessary decoration.

---

# Core Design Principles

## Content First

Content is always more important than decoration.

Design should support the content rather than compete with it.

---

## Simplicity

Every element must have a purpose.

Remove unnecessary UI.

---

## Consistency

Spacing

Typography

Animations

Buttons

Cards

Layouts

must behave consistently across the entire website.

---

## Motion With Purpose

Animation is communication.

Motion should:

- Guide attention
- Improve understanding
- Provide feedback
- Increase delight

Never animate for decoration.

---

## Accessibility

Design decisions must prioritize accessibility.

Every component should support:

- Keyboard Navigation
- Reduced Motion
- Proper Contrast
- Focus States
- Screen Readers

---

# Layout Rules

Large whitespace.

Comfortable reading width.

Clear visual hierarchy.

Avoid full-width text blocks.

# Border Radius

Use consistent radius tokens.

Medium

---

# Shadows

Soft shadows only.

Never use heavy shadows.

Elevation should remain subtle.

---

# Icons

Use one icon family consistently.

Recommended:

Lucide

Icons should always communicate meaning.

Avoid decorative icons.

---

# Images

High quality only.

Consistent aspect ratios.

Rounded corners.

Optimized for performance.

Lazy loaded.

---

# Illustration

Illustrations should support the brand identity.

Avoid generic stock illustrations.

# Accessibility Rules

Visible focus states.

Keyboard navigation.

Reduced motion support.

---

# Empty States

Every empty state should:

Explain the situation.

Suggest the next action.

Maintain brand personality.

---

# Loading States

Avoid blank screens.

Use skeleton loading where appropriate.

Loading animations should be subtle.

---

# Error States

Explain what happened.

Suggest recovery actions.

Never blame the user.

---

Shadows

Borders

Breakpoints

Never hardcode values inside components.
